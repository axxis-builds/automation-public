# automation-public

Public website for **Automation** by Axxis Builds, served with GitHub Pages at
https://axxis-builds.github.io/automation-public/

| Page | URL | Used for |
|---|---|---|
| Home | `/automation-public/` | Google OAuth consent screen: Application home page |
| Privacy policy | `/automation-public/privacy/` | Google OAuth consent screen: Privacy policy link |
| Terms of service | `/automation-public/terms/` | Google OAuth consent screen: Terms of service link |

Plain HTML and CSS, no build step. Fonts: Instrument Serif, Geist and Geist Mono (Google Fonts).

Keep the privacy policy in step with what the Automation backend actually collects and does
with Google user data. Update the "Effective" and "Last updated" dates when it changes.
